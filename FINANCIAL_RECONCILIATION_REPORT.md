Дата: 01.11.2026. Пользователь разрешил только чтение рабочих финансовых записей.

**Статус: BLOCKED — рабочий PostgreSQL остановлен.** `project_oraz-postgres-1` обнаружен в состоянии Exited, конфигурация указывает на внутренний Docker host postgres:5432. Самостоятельный запуск не выполнен: старт сервера может выполнять recovery-записи. Запрошен источник работающей БД/копии или отдельное разрешение запуска.

Количество затронутых рабочих записей, суммы расхождений, записи без объекта, дубликаты и записи без подтверждений: **UNVERIFIED**, значения не выдумывались.

Подготавливается инструмент `backend.finance.reconciliation`: транзакция PostgreSQL REPEATABLE READ READ ONLY, только whitelisted финансовые колонки, без имён/паспортов/банков. Никакие суммы, ledger, expenses, назначения или история работников этим анализом не исправляются. Корректировки возможны только после проверки отчёта и отдельного разрешения, через существующий аудируемый механизм ledger correction / legacy expense linking с expected amount/revision.
