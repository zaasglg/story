# РЕЙТИНГ

Start 5.0; min 0; max 5.
- Прогул: -0.1
- 14 consecutive days without absence: +0.1
- Без пояса: -2.0
- Без очков: -0.2
- Без каски: -0.9

Absence resets the 14-day streak.
Rating is event-driven; nobody can manually type a final rating.
Each event stores date, reason, delta, actor, optional photo.
Red/absence history remains permanently.
