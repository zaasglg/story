## Установка и оставшиеся действия

Подготовлена отдельная конфигурация Backend/PostgreSQL/Redis/HTTPS proxy: compose.server.yaml, deploy/SERVER.md, deploy/Caddyfile. Генератор deploy/generate_server_env.py создаёт независимые production secrets с0600 и отказывается перезаписывать ключи. Реальные ключи/базы в Git не включаются.

Рабочие контейнеры проекта остановлены: именно поэтому localhost:8000 не подтверждает мобильную сессию. Работающий удалённый API нужно проверить по /health/ready и задать приложению API_BASE_URL. Рабочая финансовая сверка, миграция существующей production-базы, аппаратная voice/push приёмка и off-host backups остаются отдельными действиями. Не считать их выполненными из-за успешных тестов/сборки.
